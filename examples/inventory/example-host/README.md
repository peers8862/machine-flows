# inventory/<host>/ (example layout)

`inventory/` holds one folder per machine, generated by `scripts/inventory-linux.sh` or `scripts/inventory-macos.sh` and then kept current by agents. It names real hostnames, paths, packages and services, so it stays local. This stub shows the files so you can recognise them.

| File | Contents |
| --- | --- |
| `00-summary.md` | One-page summary: OS, hardware, disks, what is notable |
| `10-system.md` | Kernel, boot, users, storage layout |
| `20-packages.md` | Package managers and installed packages |
| `30-cli-tools.md` | Command-line tools and versions |
| `40-gui-apps.md` | Desktop applications |
| `50-ai-tools.md` | AI tools, their config locations and MCP servers (names and URLs only, never tokens) |
| `60-shell-dotfiles.md` | Shell setup and dotfiles |
| `70-services-network.md` | Services and network (no addresses of private networks in public copies) |
| `75-custom-startup-services.md` | Login and boot services you created, one row each |
| `76-custom-scheduled-jobs.md` | Cron jobs, launchd and systemd timers you created, one row each |
| `80-workflow-folders.md` | Project and working folders |
| `docs-index.csv` | Index of the machine-flows documents and config files on this machine |
| `raw/` | Raw command output the summaries were built from |

Rules that go with it: when you create, change or remove a login or boot service, update `75-...`; for a scheduled job, update `76-...`; when you create, retire or move a machine-flows document, update that machine's `docs-index.csv`. The combined workbook `inventory/docs-index.xlsx` is generated only on request.
