# examples/

Placeholder versions of the machine-flows areas that stay local. Everything here is generic: made-up names, no real hosts, accounts or paths. Copy a stub to the real location and fill it in.

| Stub | Real location | What it is |
| --- | --- | --- |
| `inventory/example-host/README.md` | `inventory/<host>/` | Layout of a machine inventory |
| `service-settings/README.md` | `service-settings/` | Shared per-service settings and their precedence |
| `service-memories/README.md` | `service-memories/`, `files/` | Lessons and inbox layout |
| `plans/README.md` | `plans/README.md` | The planning-document convention |
| `mcp/servers.example.yaml` | `mcp/servers.yaml` | MCP server manifest format (no secrets) |
| `subsystem.toml` | `subsystems/<id>/subsystem.toml` | A small working subsystem manifest |
| `subsystems/README.md` | `subsystems/README.md` | Subsystem schema and commands |
| `secrets.toml.example` | `~/.config/mach/secrets.toml` | Placeholder secrets file (the real one is never in the folder) |
| `SERVICES.example.md` | `ai-tools/SERVICES.md` | Shape of a subscriptions table |
